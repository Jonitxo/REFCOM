    Nuevo modelo

    Nueva serie / grupo

    Una pieza asignada a una serie, franja o grupo se aplica a todos sus modelos, incluidos los que se añadan después.

    Nueva pieza

    Añadir varias piezas

    Si una referencia ya existe, se le añaden los modelos seleccionados. Las referencias se normalizan: «d0e3 3060» y «D0E3-3060» quedan como D0E33060.

    Importar tabla (Excel o CSV)

    Pega filas copiadas desde Excel o carga un archivo CSV. Con cabecera se reconocen las columnas: Modelo, Tipo, Referencia, Descripción, Uso, Notas, Serie, Familia, Franja, Códigos, Plataforma y Verificar. Sin cabecera se asume el orden Modelo, Tipo, Referencia, Descripción. Una fila sin modelo se importa como pieza general. Es el mismo formato que «Exportar CSV». La importación añade y amplía; no borra nada.

    Tipos de pieza

    Define las columnas de las matrices. El orden de esta lista es el orden de las columnas; los tipos con el mismo sistema se agrupan bajo una cabecera común. «Color» asigna K, C, M o Y (unidades reveladoras). «Común de serie» coloca la pieza en el bloque «Común a toda la serie». «Alias» reparte un tipo en varias columnas (PCU K+COL → PCU K, PCU COL).
